# 연대기 자료 확장 — 2026-11-01

운영 DB는 현재 639개입니다. 90개에서 443개 확장 후 영화·드라마 106개를 추가했으며 기존 사건 ID·개인 기록·기억 선택은 유지했습니다. 1950~2026년의 77개 연도 모두에 자료가 있지만, 각 연도의 모든 주요 사건을 빠짐없이 수록했다는 뜻은 아닙니다.

## 자료와 기준

- 국가기록원 ‘연표와 기록’의 1950~2003년 연도별 페이지 54개에서 사건명·기준일을 확인했습니다. 설명문·기록물 이미지·원문은 복제하지 않았습니다. 계획·선전성 표현·중복·불명확한 시점과 알려진 날짜 충돌은 제외했습니다.
- KARI의 공식 연혁에서 우주개발·발사·기술 성과를 추가했습니다. 월까지만 공개된 이력은 월 정확도를 유지했습니다.
- 유네스코 공식 목록의 유산 이름·등재 연도만 사용했습니다. 2001·2003·2005년 걸작 선정과 2008년 이후 대표목록 제도를 구분했습니다.
- KBO 공식 수상 명단에서 역대 MVP를 보완했습니다. 연도만 확인된 항목을 임의의 시상식 날짜로 바꾸지 않았습니다.
- 한국대중음악상 공식 수상 아카이브에서 음악인·음반·수상 연도와 일부 발매일을 확인했습니다. 심사평·가사·사진은 사용하지 않았습니다.
- 각 사건의 sources에 기관·원문 URL·확인일·권리 정보를 보관했습니다. ‘verified’는 원문 출처와 대조한 수록 상태이며, 모든 사실을 여러 독립 사료로 재검증했다는 의미는 아닙니다.

## 제외와 중복

## 적용·검증

`supabase/thatday/005_history_expansion.sql`은 이미 운영 DB에서 실행했습니다. 추가 사건과 그 출처만 갱신하며, 기존 개인 기록·기억 선택은 삭제하지 않습니다. 재실행 시 중복 생성하지 않습니다.

초기 확장 검증에서 실제 PostgreSQL(PGlite)로 총 533개 저장, 반복 실행, 기존 ID 유지, 전체 페이지 조회 및 출처 보존을 확인했습니다. 전체 테스트 44개와 구문 검사·빌드를 통과했습니다. 사이트에는 현재 조회 범위의 사건 수를 함께 표시합니다.
