# 기억 탐험 UX 업데이트 — 2026-11-01

## 기존 구조 분석

정적 HTML/CSS/JS와 URL 쿼리 라우팅(view/date/category/q/event)을 유지합니다. Supabase 익명 기기 세션·선택 기억·개인 기록·공개 검수 RPC를 사용합니다. 사건과 직접 연결된 기록(related)과 같은 날의 별개 기록(same_date)을 기존 스키마가 이미 구분합니다. event_lives RPC는 승인된 공개 기록 및 호출자 본인의 비공개/검토 대기 기록만 반환합니다. 기존 SQL 001~003의 권한·RLS를 유지했습니다.

기존 구현에는 별도 기억 선택과 상세 펼치기, 실제 참여자 수, 인라인 이야기와 페이지 추가 조회, 비공개 기본값이 이미 있었습니다. 이번에는 이를 교체하지 않고 아래의 단절을 보완했습니다.

## 변경

- TIME INDEX: 현재 페이지 밖에 있는 기억한 사건도 해당 연도에 붉은 점 표시. aria-label로 ‘기억한 사건 있음’을 함께 전달. 스크롤 중 화면에 들어온 연도를 미세하게 강조.
- 전체 기록/나의 기억 전환: 연도·검색·분야 맥락 보존.
- 나의 기억: 모든 페이지의 기억 사건과 본인 기록을 읽은 후 하나의 날짜순 목록으로 병합. 서로 다른 API 페이지 수 때문에 오래된 개인 기록이 뒤늦게 나타나는 문제 방지.
- 기억 선택: 즉시 먹색·붉은 점 표시, 저장 오류 시 복구, 동일 사건의 빠른 중복 요청 차단. 로그인 없는 신규 참여자도 익명 기기 보관함을 준비한 뒤 서버에 저장.
- 사건별 이야기: 닫힌 상태에서는 이야기 내용을 생성하지 않음. 이미 불러온 내용은 재사용. 실제 참여자가 있을 때 수 표시. 빈 기록에는 첫 이야기 안내. 상세 접기와 이야기 접기를 연결.
- 개인 기록은 닉네임만 약간 강조. 원문과 은/는 처리 유지. 관련 기록을 전체 목록과 사건 아래에 동시에 반복 표시하지 않음.
- 사건 아래 작성: 날짜 자동 전달, ‘이 사건과 관련된 기억/같은 시기의 별개 이야기’ 선택. 날짜 정확도와 문장 표시 방식은 추가 옵션으로 제공. 기존 기록은 정확도를 유지하며 월·연도·사건 무렵을 임의의 정확한 날짜로 확정하지 않음.
- 저장 후: 원래 스크롤을 유지하고 해당 사건 패널에 본인 기록 삽입. 비공개·공개 검토 중 상태 표시. 같은 날로 확정할 수 없는 본인 기록은 날짜가 불확실하다는 설명과 함께 따로 표시. 독립 비공개 기록도 저장 직후 본인에게 표시.
- 저장 실패 시 폼과 원문 유지. 저장 중 중복 제출 및 닫기 차단. 닫힘/삽입/붉은 점에 절제된 모션, reduced-motion 지원.

## DB 변경

없음. 기존 RPC와 RLS·검수 규칙을 사용합니다. 새 SQL 실행이 필요하지 않습니다. 운영 개인 기록이나 역사적 사건 자료를 변경하지 않았습니다.

## 검증

전체 테스트 58개 통과(실제 PostgreSQL 엔진 PGlite 권한/개인정보 테스트 포함). DOM 통합 테스트에서 즉각적인 선택·중복 선택 차단·서버 오류 복구·별도 펼치기·실패한 폼 원문 유지·비공개 저장·같은 날 관계·인라인 삽입·나의 기억 통합·필터 보존을 확인했습니다. 마지막 날짜 표기 보완 뒤 해당 DOM 테스트를 재실행했고 통과했습니다. JavaScript 구문 검사와 정적 빌드 통과. 결과 14개 파일 약 846KB.

DOM 테스트 실행 시 THATDAY_JSDOM_MODULE에 jsdom 모듈 경로, PostgreSQL 테스트 시 THATDAY_PGLITE_MODULE에 PGlite 경로를 전달합니다. 이 두 테스트 런타임은 임시 디렉터리에 설치했고 운영 웹사이트 의존성을 추가하지 않았습니다.

## 확인하지 못한 사항·범위

브라우저 제어가 Work 설정에서 꺼져 있어 실제 iOS/Android 키보드·화면 치수·모션·스크롤 안정성의 실기기 검증 및 이번 수정의 새 스크린샷은 확보하지 못했습니다. DOM 테스트는 시각적 검증을 대신하지 않습니다. The Pudding 참고 문서의 시간 진행·점진 공개 구성은 확인했지만 실제 인터랙션 재생은 확인하지 못했습니다.

특별 에피소드 제작, 좋아요·댓글·팔로우·점수·배지, 별도의 기억 지도 화면은 이번 변경에 포함하지 않았습니다. 출처 페이지·로그인/기기 보관함·개인정보 및 검수 기능은 유지합니다. ‘나의 기억’은 정확한 병합을 위해 전체 본인 기록을 페이지별로 읽으므로 매우 큰 개인 보관함은 향후 통합 서버 페이지 API로 최적화할 수 있습니다.
