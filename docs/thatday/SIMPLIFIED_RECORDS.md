# 작성 흐름 단순화 및 선수 기록

연도 눈금은 가로 스크롤·키보드 탐색을 유지하고 스크롤바만 숨겼습니다. 날짜 이동은 date 입력 하나로 통일했습니다.

상단 기록 남기기: 날짜·내용·이름·공개 범위. 특정 사건 아래 기록 남기기: 사건 날짜를 자동 전달하고 관련 기억으로 저장. 관계·날짜 정확도·문장 형식 선택과 반복 미리보기를 없앴습니다. 새 글은 이름 뒤 콜론과 원문을 표시해 짧은 감상·구어체가 어색하지 않게 했습니다. 기존 글의 표현 방식·관계·불확실한 날짜는 편집만으로 바뀌지 않습니다. 기본 비공개와 공개 전 명시적 동의·검수는 유지합니다.

스포츠 선수별 메달·MVP 8건을 공식 출처로 확인하고 운영 DB에 반영했습니다. 기존 82건 → 총 90건, 스포츠 11건. 제목 끝의 마침표를 정리했고 개인 기록 원문은 수정하지 않았습니다. 004_sports_titles.sql은 이미 실행했으므로 다시 실행할 필요 없습니다.

테스트 42개·구문 검사·빌드 통과. 모바일에서 사건 작성(날짜 입력 없음), 일반 작성(날짜 입력 1개), 단일 날짜 이동, 가로 넘침 없음 및 scrollbar none 확인. 공감 버튼은 이번 범위에 포함하지 않았습니다.
