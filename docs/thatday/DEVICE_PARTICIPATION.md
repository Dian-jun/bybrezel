# 로그인 없는 기기별 참여

이메일·소셜 로그인 화면을 거치지 않고 작성 버튼에서 Supabase 익명 세션을 자동 생성합니다. 기록 소유권과 기존 RLS/검수/수정/삭제 권한은 유지합니다. 표시 이름은 자동으로 생성하고 작성창 안에서 변경할 수 있습니다.

나의 기록 접근 정보는 쿠키 대신 브라우저 localStorage에 저장되는 Supabase 세션으로 보관합니다. 본문·공개 범위·검수 상태는 Supabase에 저장합니다. 같은 기기의 같은 브라우저에서만 보관함을 다시 열 수 있습니다. 쿠키/사이트 데이터 삭제, 시크릿 모드 종료, 브라우저 또는 기기 변경 시 익명 소유권은 복구할 수 없습니다. 설정의 JSON 내보내기를 사용할 수 있습니다. 지운 식별 정보로 기존 데이터를 재연결하거나 다른 사람의 자료를 찾지 않습니다.

Supabase Authentication → Sign In / Providers → Allow anonymous sign-ins를 활성화했습니다. 기존 이메일 인증과 RLS는 유지했습니다. 새 SQL 마이그레이션은 필요 없습니다. 익명 사용자 생성은 방문할 때마다 하지 않고 최초 참여 때만 하며, SDK 세션을 재사용합니다. 동시 요청은 하나로 합칩니다.

검증: 전체 38개 테스트와 빌드 통과. 실제 프로젝트에 비공개 QA 기록 저장 후 같은 브라우저 재방문에서 유지 확인. 공개 API 검색에서 해당 QA 기록 0건 확인. 운영 공개 기록에는 테스트 문장을 게시하지 않았습니다. 실물 폰의 장기 보관 기간은 브라우저의 사이트 데이터 보존 정책에 따릅니다.
