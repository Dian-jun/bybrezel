Sub Camera

Sub Camera는 사진을 촬영하고, 앱 내부 보관함에 로컬 저장하고, 폴더와 메모, 마크업으로 정리할 수 있도록 설계된 카메라 앱입니다.

개인정보처리방침 보기 지원 및 문의

로컬 저장 중심

사진과 메모는 기본적으로 사용자의 기기 내부 앱 저장소에 보관됩니다.

정리와 기록

폴더, 메모, 마크업 기능을 통해 사진을 목적에 맞게 정리할 수 있습니다.

선택적 권한 사용

위치 정보, 사진 가져오기, 문의 메일 전송은 사용자가 직접 허용하거나 실행할 때만 작동합니다.

자주 묻는 내용

사진은 어디에 저장되나요?

기본적으로 사용자의 기기 내부 앱 저장소에 보관됩니다. 사용자가 직접 공유하거나 내보내지 않는 한 자동 업로드되지 않습니다.

데이터 삭제는 어떻게 요청하나요?

앱 내부 데이터 삭제 문의는 hello@bybrezel.com으로 요청할 수 있습니다. 요청 시 가능한 범위에서 확인 및 안내를 제공합니다.

위치 정보는 언제 저장되나요?

사용자가 위치 권한을 허용한 경우에만 촬영 시점의 위치 정보가 사진 정보에 함께 기록될 수 있습니다.
